# Dataset

`jobs_demo.csv` (generated by `scripts/generate_sample_data.py`) is
**DEMO DATA — NOT REAL MARKET DATA**, used only so the whole app runs
out of the box.

## Using a real dataset

Download a public job-postings dataset (e.g. a Kaggle "job postings" or
"LinkedIn job postings" dataset) and place the CSV here as
`jobs_real.csv` with (at minimum) these columns — rename columns to
match if needed:

| column            | required | notes                                |
|-------------------|----------|---------------------------------------|
| title             | yes      | job title                             |
| company           | no       |                                        |
| city, state, country | no    | any subset is fine                    |
| salary            | yes      | numeric annual salary                 |
| experience_level  | no       | Entry / Mid / Senior                  |
| experience_years  | no       | numeric                               |
| description       | yes      | free text, used for skill extraction  |
| skills_raw        | no       | comma-separated skills if available   |
| employment_type   | no       |                                        |
| industry          | no       |                                        |
| education         | no       |                                        |
| date_posted       | no       | enables trend charts                  |

Then run:

```
python scripts/process_dataset.py data/raw/jobs_real.csv
python scripts/train_salary_model.py
python -m src.utils.db
```
